# Portfolio Boundary

RyVora is a **simulated, synthetic/non-PHI portfolio application**.

It demonstrates:

- Healthcare business analysis
- RCM workflow understanding
- Product and solution design
- Interoperability concepts
- Analytics and KPI validation
- Application delivery
- AI/HITL governance concepts
- Automation opportunities
- Testing and validation

It does not represent:

- Production deployment
- Live payer connectivity
- Production PHI processing
- HIPAA certification
- Autonomous AI decision-making
- Live external automation
- Production authentication/authorization/persistence

This distinction is intentional and should remain visible in public portfolio materials.
