# Services boundary

Current local services orchestrate validated workbook projections and module business selectors for Dashboard, Claims, Denials, Payments, AR, Exceptions, Interoperability, Analytics, Automation, and AI/HITL. Automation composes existing module records and derives candidate eligibility only; this source has no workflow execution records, write controls, API clients, or database adapters. AI/HITL composes the existing Denials service projection; it introduces no AI client, persistence, or write service. Audit_Trail is a claim lifecycle source and is not presented as automation run history or user-action history. Analytics composes existing module records for the current page session; it does not establish a new dataset, API, or database. Future API clients belong here when an approved feature requires them; keep transport and authentication concerns out of UI components and business calculations, and use explicit versioned contracts for exchanges such as FHIR or X12.
